## LyftrAi Logo System

A minimal brand page showcasing the LyftrAi gradient logomark, supporting wordmark, and quick usage notes. Built with Next.js 16, Tailwind CSS v4, and deployed-ready for Vercel.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the logo presentation.

## Key Files

- `public/lyftrai-logo.svg` – primary scalable logomark export
- `src/app/page.tsx` – hero layout, brand guidelines, download CTAs
- `src/app/globals.css` – theme tokens and global treatments

## Building & Deployment

```bash
npm run build
npm start
```

Ship to Vercel with `vercel deploy --prod`.
